# CallaFlorist

**Problem:** A florist shop needed an online ordering system with real-time order notifications and a beautiful catalog experience.

**My role:** Solo developer — built the full ordering pipeline from catalog browsing to Telegram-based order notifications.

**Stack:** Vue 3, FastAPI, Telegram Bot API, PostgreSQL, Tailwind CSS

**Outcome:** Live e-commerce site with instant order notifications via Telegram, serving as a reference pattern for notification-driven systems.
