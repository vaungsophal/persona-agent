# NoteAgent

**Problem:** Personal note-taking is fragmented across apps with no unified search or agentic action layer.

**My role:** Solo developer — designed retrieval pipeline and agent tool loop.

**Stack:** Python, FastAPI, LangChain, SQLite, NLP

**Outcome:** A note system where an agent can retrieve, summarize, and act on notes via natural language — proving the tool-use pattern on personal data.
