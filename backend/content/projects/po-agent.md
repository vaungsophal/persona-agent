# PO Agent

**Problem:** Standing out to recruiters and clients with a static portfolio page — needed something interactive that actually demonstrates agent-building skills.

**My role:** Creator — designed the agent architecture, tool system, and chat interface end to end.

**Stack:** Vue 3 + Pinia + Tailwind, FastAPI, AWS Bedrock (Claude), Telegram Bot API, Docker, Cloud Run

**Outcome:** A living AI twin that answers questions about my work, searches my GitHub for live activity, and captures leads via Telegram — all running on scale-to-zero Cloud Run for near-zero cost.
