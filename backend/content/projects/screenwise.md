# ScreenWise

**Problem:** Teams needed a way to capture and analyze screen activity for productivity insights without invasive monitoring.

**My role:** Full-stack lead — architected the agentic pipeline, built the FastAPI backend, and integrated AWS Bedrock (Claude) for real-time screen analysis.

**Stack:** Python, FastAPI, AWS Bedrock (Claude), WebSocket, Vue 3, PostgreSQL

**Outcome:** Delivered a working agent that captures screenshots, analyzes context via Bedrock, and surfaces actionable summaries — all with sub-second latency on the analysis loop.
